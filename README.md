## Publicar con GitHub + Render
1. Descomprime este proyecto.
2. Crea un repositorio en GitHub y sube el contenido de esta carpeta (index.html, styles.css, script.js, assets y README).
3. En Render, selecciona **New + → Static Site** y conecta el repositorio.
4. Configura:
   - Build Command: dejar vacío.
   - Publish Directory: `.`
5. Pulsa **Create Static Site**. Render entregará una URL pública.
